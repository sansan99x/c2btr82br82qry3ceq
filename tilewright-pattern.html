Langkah setelah generate
  1. Pastikan objek tidak saling menempel di gambar.
  2. Vektorkan, misalnya dengan Vectorizer.ai, atau Illustrator Image Trace dengan opsi Ignore White.
  3. Simpan sebagai satu file SVG, lalu tarik ke panel Objek. Tool memisahkan objek dan membuang latar putih otomatis.
