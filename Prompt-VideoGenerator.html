Perakit Prompt Video

Pilih tema, jenis subjek, tampilan, dan jumlah adegan. Tool ini menghasilkan hanya tiga prompt per adegan: frame awal, frame akhir, dan video. Untuk adegan manusia, karakter selalu berakting secara diam: tanpa berbicara, dialog, atau lip-sync; emosi ditampilkan melalui ekspresi wajah dan gerakan tubuh. Klik Buat prompt terlebih dahulu untuk menampilkan hasil, lalu gunakan tombol salin atau Unduh HTML.

Gerakan batch ini

Gerakan diambil acak dari kamus tema terpilih. Tombol gerakan baru menghindari batch yang sedang tampil. Setelah prompt dibuat atau disalin, gerakan dicatat sebagai terpakai; gerakan lama baru boleh muncul lagi jika kamus tema habis.

Ketik minimal 2 huruf. Klik “Masukkan ke batch” untuk mengutamakan gerakan pilihanmu pada batch berikutnya. Gerakan pilihan tetap dipertahankan saat mengambil gerakan baru dan dibersihkan setelah batch dibuat.
