Bead Brief Studio

Brief sekali untuk desain fuse bead berbentuk potongan. Unduh 3 file: template grid, skill untuk membuat gambar, dan skill untuk mengubah gambar jadi project JSON Pegwright dengan kode Artkal S dan latar kosong.

1 brief di sini2 template + skill gambar → ChatGPT3 gambar + skill JSON → AI dengan Python → Pegwright

Brief desain

Satu objek utama. Hindari tokoh bermerek (Disney, Pokémon, dan sejenisnya).

Ukuran (manik: kolom × baris)

Warna manik tidak termasuk latar (latar kosong, tanpa manik).

Simetri
Format JSON (Pegwright)

Dipakai skill JSON sebagai isi project. Tersimpan di browser ini. Bisa diambil dari project Pegwright lama.

Template grid

Cara pakai

  1. Upload grid.png + skill-gambar….md ke ChatGPT, tulis “ikuti skill ini”.
  2. Simpan gambar hasilnya (dan salin kartu CHART SPEC kalau ada).
  3. Upload gambar + skill-json….md ke AI yang bisa menjalankan Python, tulis “ikuti skill ini”.
  4. Buka JSON-nya di Pegwright: File → Open project (.json).
